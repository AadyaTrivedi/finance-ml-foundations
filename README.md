# finance-ml-foundations

Financial Stress Predictor is a data-driven system that analyzes an individual’s personal finance data (income, expenses, savings, debt, and emergency funds) to:
Predict the individual’s financial stress risk level (Low / Medium / High)
Explain why the person is financially stressed using model explainability techniques (SHAP)
Perform scenario analysis to show how changes in financial behavior (e.g., increasing savings or reducing expenses) impact stress risk
The project focuses on real-world finance logic, explainable machine learning, and actionable insights, rather than just predictive accuracy.
